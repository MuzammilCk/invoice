# Invoice Studio Model Fine-Tuning Guide (Google Colab)

Follow these steps exactly in a new Google Colab notebook to train your small 1.5B parameter model.

## Step 1: Setup Colab Environment
1. Go to [colab.research.google.com](https://colab.research.google.com/) and create a **New Notebook**.
2. Click **Runtime** > **Change runtime type**.
3. Select **T4 GPU** as the Hardware accelerator and click **Save**.

## Step 2: Install LLaMA-Factory
Create a new code cell, paste this code, and run it:
```bash
!git clone --depth 1 https://github.com/hiyouga/LLaMA-Factory.git
%cd LLaMA-Factory
!pip install -e .[torch,metrics]
```

## Step 3: Upload the Dataset and Config
1. Create a file on your local computer named `invoice_schema_dataset.jsonl` containing the synthetic data generated by the prompt I provided earlier.
2. In Colab, click the **Folder icon** on the left sidebar.
3. Open the `LLaMA-Factory/data` folder.
4. Upload `invoice_schema_dataset.jsonl` into the `data` folder.
5. In the same `data` folder, double-click `dataset_info.json`. Add this entry inside the top-level JSON object and save it:
```json
  "invoice_dataset": {
    "file_name": "invoice_schema_dataset.jsonl",
    "columns": {
      "prompt": "instruction",
      "query": "input",
      "response": "output"
    }
  },
```

6. Upload the `colab_llamafactory_config.yaml` (which I generated for you) to the `LLaMA-Factory` root directory.

## Step 4: Start the Fine-Tuning
Create a new code cell and run the training process. This will take about 10-20 minutes depending on your dataset size.
```bash
!llamafactory-cli train colab_llamafactory_config.yaml
```

## Step 5: Merge the LoRA Adapters into Base Model
Once training completes, we need to merge the trained weights back into the base Qwen 1.5B model. Create a new cell:
```bash
!llamafactory-cli export \
    --model_name_or_path Qwen/Qwen2.5-1.5B-Instruct \
    --adapter_name_or_path saves/qwen2.5-1.5b/lora/sft \
    --template qwen \
    --finetuning_type lora \
    --export_dir invoice-qwen2.5-1.5b-merged \
    --export_size 2 \
    --export_device cpu
```

## Step 6: Convert to GGUF (For Windows `llama.cpp`)
Since you are running natively on Windows via `llama-server.exe`, you need to convert the merged HuggingFace model into a quantized GGUF file.

Create a new cell to download the conversion script and convert the model to an 8-bit quantized GGUF:
```bash
%cd /content
!git clone https://github.com/ggerganov/llama.cpp
!pip install -r llama.cpp/requirements.txt
!python llama.cpp/convert_hf_to_gguf.py LLaMA-Factory/invoice-qwen2.5-1.5b-merged \
    --outfile invoice-qwen2.5-1.5b-q8_0.gguf \
    --outtype q8_0
```

## Step 7: Download the Model
Download the final GGUF file to your local computer:
```python
from google.colab import files
files.download('/content/invoice-qwen2.5-1.5b-q8_0.gguf')
```

*(Note: The file is ~1.5 GB, so downloading might take a few minutes).*

---

## Step 8: Deploying on Windows (Local Machine)
1. Move the downloaded `invoice-qwen2.5-1.5b-q8_0.gguf` to your `D:/invoice/models/` folder.
2. (Optional but recommended) Download the draft model for speculative decoding: Download `qwen2.5-0.5b-instruct-q8_0.gguf` from HuggingFace to the same folder.
3. Open a terminal and start your `llama-server.exe`:

```bash
llama-server.exe \
    -m D:/invoice/models/invoice-qwen2.5-1.5b-q8_0.gguf \
    --model-draft D:/invoice/models/qwen2.5-0.5b-instruct-q8_0.gguf \
    --draft 5 \
    --host 0.0.0.0 \
    --port 8000 \
    --n-gpu-layers 99 \
    --ctx-size 4096 \
    --parallel 4 \
    -a invoice-model
```

Your fine-tuned invoice model is now running. Ensure `LLM_MODEL="invoice-model"` in your `.env` file!
